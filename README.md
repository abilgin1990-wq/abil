# Teklif Hazırlama Programı (C# / WinForms)

Bu proje Visual Studio ile açılıp çalıştırılabilecek şekilde hazırlanmış bir WinForms teklif hazırlama uygulamasıdır.

## Özellikler
- Ana sayfada firma + proje girerek teklif oluşturma
- Teklif listesini tablo olarak görüntüleme
- Teklif detayında tesisat grubu yönetimi
- İş detayı ve malzeme listesi yönetimi
- Ayarlar ekranında:
  - Tesisat grubu / iş detayı şablon yönetimi
  - Malzeme kataloğu ve kur bilgisi yönetimi
- Dosya menüsü:
  - Ayarlar
  - Programı Kaydet
  - Programı Farklı Kaydet
  - Kapat (değişiklik varsa kaydetme sorusu)

## Çalıştırma
1. Visual Studio 2022 ile `TeklifHazirlama.sln` dosyasını açın.
2. Başlangıç projesi olarak `TeklifHazirlama` seçin.
3. `F5` ile çalıştırın.
